# Tipografia — MindCycle

## Fonte do logotipo

O logotipo (wordmark "MindCycle") usa a **Fraunces**, uma serifa suave e humanista, no peso **SemiBold (600)**.

- Arquivo: `Fraunces-SemiBold.ttf` (usado no wordmark)
- Também incluídos: `Fraunces-Regular.ttf` e `Fraunces-Italic.ttf` (para títulos e citações)
- Licença: `Fraunces-OFL-License.txt` (SIL Open Font License 1.1 — livre para uso, inclusive comercial e redistribuição)

> No arquivo final do logo (SVG), o texto já está **vetorizado** (convertido em curvas), então o logotipo não depende da fonte instalada. A fonte é fornecida aqui para materiais novos (títulos, banners, apresentações).

## Hierarquia recomendada

| Papel | Fonte | Peso |
|---|---|---|
| Logotipo / títulos de destaque | Fraunces | 600 (SemiBold) |
| Subtítulos / citações | Fraunces Italic | 400 |
| Texto corrido / interface | Nunito Sans* | 400 / 600 / 700 |
| Rótulos / dados | Nunito Sans* | 700 (com `letter-spacing`) |

\* A **Nunito Sans** é a fonte de apoio usada na interface e no site (não é a fonte do logo). Disponível gratuitamente no Google Fonts.

## Fontes no Google Fonts

- Fraunces — https://fonts.google.com/specimen/Fraunces
- Nunito Sans — https://fonts.google.com/specimen/Nunito+Sans

```html
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,600;1,9..144,400&family=Nunito+Sans:wght@400;600;700&display=swap">
```
